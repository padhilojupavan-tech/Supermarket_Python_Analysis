# 🛒 Supermarket Sales Analysis Using Python

## 📌 Project Overview

This project focuses on analysing supermarket sales data using Python. The goal is to identify sales trends, understand product performance, compare categories and locations, and generate meaningful business insights.

A visual sales dashboard was created using Pandas, NumPy and Matplotlib.

## 🎯 Project Objectives

- Analyse overall supermarket sales.
- Calculate total and average sales.
- Identify top-performing products.
- Analyse category-wise sales.
- Compare location-wise sales.
- Understand monthly sales trends.
- Visualise sales performance using charts.

## 📂 Dataset Information

- **Total Records:** 100 transactions
- **Total Columns:** 9

### Dataset Columns

| Column | Description |
|---|---|
| Order ID | Unique order identifier |
| Product | Product name |
| Category | Product category |
| Quantity | Number of units sold |
| Price | Price per unit |
| Sales | Total sales amount |
| Date | Transaction date |
| Location | Sales location |
| Payment Method | Payment type |
